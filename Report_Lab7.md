# Звіт за груповим завданням 7

До наявного REST API додано веб-інтерфейс на Thymeleaf: вхід через форму, список і форму додавання пристроїв, сторінку пристрою з командами, сторінки помилок 403, 404 і 5xx, спільні шапку й підвал та глобальні стилі.

Ланцюги безпеки: REST перенесено під `/api` і залишено на JWT (без сесій, CSRF вимкнений); для сторінок додано окремий `SecurityFilterChain` із входом через форму, сесією та увімкненим CSRF; Swagger і H2-консоль мають власний відкритий ланцюг.

Ролі: глобальних ролей немає, права визначаються роллю на конкретному пристрої (OWNER або GUEST), що зберігається в базі даних. OWNER бачить усі команди пристрою та форму додавання команди, GUEST лише команди для гостей; ті самі права перевіряються на сервері через `@PreAuthorize`.

Нижче наведено знімки сторінок для різних ролей.

### Помилка входу
![Помилка входу](docs/screenshots/lab7/02-login-error.png)

Результат: після неправильного пароля показується повідомлення «Неправильна адреса електронної пошти або пароль.».

## Власник (OWNER)

### Мої пристрої
![Список пристроїв власника](docs/screenshots/lab7/03-owner-devices.png)

Результат: таблиця пристроїв власника з типом, роллю OWNER і датою; після створення пристрою зверху показується повідомлення «Пристрій «Кавомашина» додано». У шапці видно електронну пошту користувача й кнопку «Вийти».

### Форма додавання пристрою з помилками
![Форма з помилками](docs/screenshots/lab7/04-owner-new-device-errors.png)

Результат: при порожніх даних форма лишається відкритою, поля підсвічені, під ними повідомлення «Вкажіть назву пристрою» та «Оберіть тип пристрою».

### Сторінка пристрою
![Пристрій власника](docs/screenshots/lab7/05-owner-device-details.png)

Результат: власник бачить усі команди пристрою (`set_brightness` для власника, `turn_on` для гостей) і форму «Додати команду».

### Дублікат назви команди
![Дублікат команди](docs/screenshots/lab7/06-owner-command-duplicate-error.png)

Результат: спроба додати команду, що вже існує, повертає на сторінку пристрою з помилкою «Команда з такою назвою вже існує» біля поля назви.

## Гість (GUEST)

### Мої пристрої
![Список пристроїв гостя](docs/screenshots/lab7/07-guest-devices.png)

Результат: гість бачить лише пристрій, до якого йому надано доступ, з роллю GUEST.

### Сторінка пристрою
![Пристрій гостя](docs/screenshots/lab7/08-guest-device-details.png)

Результат: гість бачить лише команди, доступні гостям (`turn_on`), форми «Додати команду» немає.

### Заборонена дія
![Сторінка 403](docs/screenshots/lab7/09-guest-403.png)

Результат: прямий запит гостя на додавання команди завершується сторінкою «Доступ заборонено» (403).
